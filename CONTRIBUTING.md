# Contributing to targeted-mutation

Thank you for your interest in contributing to `targeted-mutation` (`cargo tmt`).

## Requirements

- Rust **1.88 or newer** (MSRV is checked in CI via `cargo +1.88.0 check --all-targets`).
- Optional formal-verification tools: Lean 4, PICT, and TLA+ / TLC (`tla2tools.jar`) — see [formal/README.md](formal/README.md).

## Development & testing

```sh
# Format and lint
cargo fmt --check
cargo clippy --all-targets -- -D warnings

# Fast unit, binary, parity, and doc tests
cargo test --lib --bins --test parity
cargo test --doc

# Full test suite (unit tests, PICT tables, property tests, E2E on fixtures/)
cargo test
PROPTEST_CASES=256 cargo test --test properties

# Heavy source-vs-probe equivalence suite (several minutes)
cargo test -- --ignored

# Run cargo tmt on itself
cargo run -- .
```

The stored mutation lists in `tests/data/cargo-mutants` are generated by running `cargo mutants --list` in a copy of each fixture crate and compared against `cargo tmt` in `tests/parity.rs`.

## Releasing

1. Update the version in `Cargo.toml` and `Cargo.lock`, and add release notes to [CHANGELOG.md](CHANGELOG.md).
2. Verify locally:
   ```sh
   cargo fmt --check
   cargo clippy --all-targets -- -D warnings
   cargo +1.88.0 check --all-targets
   cargo test --lib --bins --test parity
   cargo test --doc
   cargo publish --locked --dry-run
   ```
3. Push the release commit to `main` and wait for the [CI workflow](https://github.com/t-k/targeted-mutation/actions/workflows/ci.yml) to pass on that exact commit.
4. Optionally run the [Release workflow](https://github.com/t-k/targeted-mutation/actions/workflows/release.yml) manually (`workflow_dispatch`) to verify the package in CI.
5. Create and push a signed tag matching the crate version (e.g. `git tag -s v0.7.0 -m "Release v0.7.0" && git push origin v0.7.0`).
   The Release workflow verifies that the tagged commit is on `main` with a green CI run, validates the package again, and publishes it to crates.io via Trusted Publishing.
6. Create a GitHub Release for the tag using the corresponding section of [CHANGELOG.md](CHANGELOG.md).
